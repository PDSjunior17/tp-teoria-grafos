## 📁 Estrutura do Projeto
```
tp-teoria-grafos/
├── src/
│   ├── data_mining/      # Coleta de dados do GitHub
│   ├── graph/            # Classes de grafo (lista e Matriz) e Construção de grafos
│   └── analysis/         # Análises e métricas
├── data/
│   ├── raw/              # Dados brutos
│   └── processed/        # Dados processados
├── docs/
│   └── relatorio/        # Relatório LaTeX
├── tests/                # Testes
└── requirements.txt
```

## 🚀 Como Executar
```bash
# Instalar dependências
pip install -r requirements.txt

# Executar mineração
python run_etapa1.py

# Executar Dashboard de Análise de Grafos
python dashboard_pro.py #abra o arquivo dashboard_pro.html no navegador
```
Etapa 2: 
```bash
# No diretório `src`, execute:
javac -encoding UTF-8 graph/*.java

# Após a compilação, execute:
java graph.Main

```
