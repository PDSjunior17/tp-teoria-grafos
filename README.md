## 📁 Estrutura do Projeto
```
tp-teoria-grafos/
├── src/
│   ├── data_mining/      # Coleta de dados do GitHub
│   ├── graph/            # Classes de grafo
│   └── analysis/         # Análises e métricas
├── data/
│   ├── raw/              # Dados brutos
│   └── processed/        # Dados processados
├── docs/
│   └── relatorio/        # Relatório LaTeX
├── tests/                # Testes
└── requirements.txt
```

## 🚀 Como Executar
```bash
# Instalar dependências
pip install -r requirements.txt

# Executar mineração
python run_etapa1.py

# Executar análises
python src/analysis/run_analysis.py
```
